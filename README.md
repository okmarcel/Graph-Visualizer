# Graph Visualizer

Standalone application to visualize graphs and algorithms on graphs.

![Demo Screenshot](.github/demo_screenshot.png)

## Prerequisites

- Java SDK 21
- JUnit 5

## Building

Use gradle to build and run the project automatically with:
```
./gradlew run
```

or just to build:
```
./gradlew build
```

To clear cache after build run:
```
./gradlew clean
```
